# 映画上映館検索アプリ

これから上映する映画を検索し、どの映画館で上映されるかを推測するPyQt5アプリケーションです。

## 機能

- 🔍 **映画タイトル検索**: 映画のタイトルで検索
- 📅 **公開予定判定**: 映画が今後上映予定かどうかを自動判定
- 🏢 **映画館推測**: 映画のジャンルやタイトルから上映される可能性のある映画館を推測
- 🎬 **詳細情報表示**: 公開日、ジャンル、監督、出演者などの情報を表示
- 📋 **公開予定一覧**: これから公開される映画の一覧表示

## 映画館推測ロジック

このアプリケーションは、以下の情報を元に上映される可能性のある映画館を推測します：

### 推測に使用する要素
- **映画のジャンル**: アニメ、アクション、ドラマなど
- **タイトルのキーワード**: ディズニー、マーベル、アニメ作品名など
- **作品の規模**: 大作、ミニシアター系など

## インストール方法

### 1. 必要なライブラリのインストール

```powershell
pip install -r requirements.txt
```

### 2. アプリケーションの起動

```powershell
python main.py
```

## 使い方

1. **映画を検索する**
   - 検索ボックスに映画のタイトルを入力
   - 「🔍 検索」ボタンをクリック、またはEnterキーを押す
   - 検索結果が左側のリストに表示されます

2. **詳細情報を確認する**
   - リストから映画を選択
   - 右側に詳細情報が表示されます
   - 上映予定の映画館リストも表示されます

3. **公開予定映画を見る**
   - 「📅 公開予定一覧」ボタンをクリック
   - これから公開される映画のリストが表示されます

## 情報源について

このアプリケーションは以下のソースから情報を取得・推測します：

- **映画.com** (https://eiga.com/)
  - 映画の基本情報、公開日、ジャンルなど

- **Yahoo!映画** (https://movies.yahoo.co.jp/)
  - 映画の詳細情報、レビューなど

- **推測ロジック**
  - タイトルやジャンルから映画館を推測
  - 実際の上映情報は各映画館の公式サイトで確認してください

## 注意事項

⚠️ **重要な注意点**

1. **上映館情報の精度**
   - このアプリケーションの映画館情報は「推測」です
   - 実際の上映館は各映画館の公式サイトで必ずご確認ください

2. **Webスクレイピングについて**
   - 現在の実装はデモ版です
   - 実際のWebスクレイピングを行う場合は、各サイトの利用規約を確認してください
   - robots.txtの確認と遵守が必要です

3. **データの正確性**
   - 映画情報は常に最新とは限りません
   - 公式サイトで最終確認することをお勧めします
