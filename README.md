# 映画チェッカー

観たい映画が「いま映画館でやっているか」「いつ公開か」を、代わりに毎日見ておいてくれる Windows のアプリです。映画.com (eiga.com) の情報を使います。個人で使う無料の物で、広告も会員登録もありません。

## 入れ方

1. [Releases](../../releases) から `映画チェッカー-setup-x.x.x.exe` をダウンロードして開きます。
2. 青い画面 (SmartScreen) が出たら『詳細情報』→『実行』。個人が作ったアプリなので初回だけ止められます。
3. スタート メニューの『映画チェッカー』から起動します。新しい版も同じ手順で上書きできます。

## 使い方

- **観たい映画を登録する**: 右の『ウォッチリスト』にタイトルを入れて『追加』。上映中なら 🟢、まだなら『📅 11/14 公開』、終わっていれば ⚪ になります。ダブルクリックで近くの映画館が出ます。
- **監督で追う**: 『監督』のタブに名前を入れると、その監督の作品が全部入ります。
- **映画館で追う**: 『映画館』のタブで好きな館 (ミニシアターも) を登録すると、その館の今の上映作品が並びます。
- **おすすめ**: 左上に今日の候補が並びます。気分 (笑いたい・泣きたい・迫力・静かに) で絞れます。『観たい』『いまいち』『観た』を押すほど、あなたの好みに寄っていきます。
- **メールで知らせる**: 上の『メール』で Gmail などを設定すると、新しく上映になった時と週 1 回のまとめが届きます。

## 安心のために

- 登録した映画や好みは、あなたの PC の中 (`%APPDATA%\映画チェッカー`) にだけ保存します。どこにも送りません。
- メールのパスワードは Windows の資格情報に保存し、ファイルには書きません。
- インターネットに出るのは映画.com を見に行く時だけ (起動時と 6 時間ごと)。
- アンインストールしても保存した物は残ります。消したい時はそのフォルダを削除してください。

## 困った時

- 一覧が空のまま: インターネットにつながっているか確かめて『更新』を押してください。上の帯に理由が出ます。
- メールが届かない: 『メール』の『試しに送る』を押すと、何が足りないかが出ます。Outlook / Hotmail は今は使えません (Microsoft の仕様)。
- 見た目を白にしたい: 上の『外観』。

## 開発する人へ

Python 3.13 + tkinter。中身は `app/moviecheck/` (取得・照合・通知・好み・おすすめ)、画面は `app/movie_app.py`。

```
python -m venv .venv
.venv\Scripts\pip install -r app/requirements.txt -r app/requirements-dev.txt
cd app
..\.venv\Scripts\python movie_app.py
..\.venv\Scripts\python -m pytest -q
```

固める (setup.exe): `packaging\build.ps1` (版は `app/moviecheck/version.py` だけ上げる)。setup.exe は git に入れず Releases に付けます。源から動かした時のデータは `app/` の隣に出来て、`.gitignore` と `tests/test_repo.py` が git に入らないよう守っています。

決まり: 既存の挙動は変えずに足す。会社の情報は扱わない。鍵は json や源に書かない。外の AI には送らない。
